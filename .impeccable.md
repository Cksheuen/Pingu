## Design Context

### Users

One technical user operating a personal VPS from a desktop. The main job is to
connect quickly, see whether the current network lease is valid, and understand
traffic and node health without opening a terminal.

### Brand Personality

Calm, exact, personal. The interface should feel like a well-made instrument:
quiet when healthy, explicit when something needs attention, and fast at the
one action that matters.

### Aesthetic Direction

Eva Blog's Silverwing palette is the product reference: ice-white and blue-gray
surfaces, a graphite structural shell, restrained cobalt interaction color, and
small cyan energy/focus details. The desktop may stay dark where that improves
operational scanning, while public pages should use the pale armored surfaces.
Avoid purple gradients, glassmorphism, generic rounded-card grids, overused
fonts, and decorative effects that do not communicate state.

### Design Principles

1. Make connection state and the primary connect/disconnect action the visual
   anchor of Home.
2. Treat the current network lease as a first-class operational fact, not a
   hidden setting.
3. Use asymmetry, compact labels, and a distinctive display face paired with a
   readable UI face; keep body text short and scannable.
4. Use motion only to explain state transitions and honor reduced-motion users.
5. Preserve a high-signal desktop layout with keyboard-visible focus and clear
   error recovery.
6. Use the canonical Eva tokens for shared identity: `#f7faff`, `#eef4fc`,
   `#dde6f3`, `#0f1420`, `#161e30`, `#2f6fe4`, `#4fd6f5`.
