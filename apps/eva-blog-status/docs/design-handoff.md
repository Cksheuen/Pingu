# Design handoff

The status publisher uses the Eva Blog Silverwing visual language: graphite
shell, ice-white surfaces, cobalt action color, cyan connection signal, and a
compact mono metadata layer. The page is intentionally operational and local:
the API origin, author session, status form, and recent public pulses are the
only primary surfaces. Background reporting is represented as a compact agent
heartbeat and setup flow: cyan states distinguish live, idle, and error, while
the copy makes the private-safe payload boundary explicit. The browser
intentionally has no recurring reporting timer.
